# UI/UX 优化轮与「纯白工具覆盖」采用记录（2026-10-10）

核验日期：2026-10-10（Asia/Shanghai）。规范依据：`project-standards` 当前 `d0313b8` 版本的 `design/visual-style.md`、`design/ui-design.md`、`design/ux-interaction.md`、`design/color-and-theme-modes.md`、`design/responsive-design.md`、`design/accessibility.md`、`design/motion-and-performance.md`，以及配方 `design/themes/white-paper-ink.md`。范围：桌面与移动端全部页面、弹层与地图工作台；地图底图与高德内嵌控件除外。

## 主题配方采用

RongMap 为地图工具型产品，采用「纯白工具覆盖」（`themes/white-paper-ink.md`，早期版本曾名「白纸油墨编辑风」）：纯白纸面 + 近黑油墨 + 单一 #FFE28A 强调色 + 32px 网格，工具型布局与较低动效（沿用前次记录：`DESIGN_VARIANCE 4 / MOTION_INTENSITY 3 / VISUAL_DENSITY 6`）。采用范围：全站。

**Token 对照（配方起始值 → 现行值）与偏离说明**

- canvas / surface：`#FFFFFF` → `#FFFFFF`；surface-subtle：`#F7F7F3` → `#F7F7F3`
- text-primary：`#1A1A1A` → `#1A1A1A`；text-secondary：`#555555` → `#656565`（白底 5.83:1，保留现状）
- text-subtle：`#6B6B6B` → `#6B6B6B`（本轮由 `#929292` 调整：对比度 3.11:1 → 5.33:1，修复文字可读性）
- border：`#E8E8E8` → `#E3E3DF`（贴合纸面暖调的装饰性边界，保留）
- border-interactive：`#8E8E8E` → `#82827C`（2026-10-08 移动端核验调整：对白面 3.87:1、对 surface-subtle 3.60:1、对浅黄 3.04:1，均达 3:1）
- accent：`#FFE28A` → `#FFE28A`；focus：`#315EFB` → `#315EFB`（焦点环附加固定 20% 透明度：`--focus-ring`）
- success：`#2E6F4E` → `#28704B`（近似替代，白底 5.98:1）；warning `#8A6410`（5.37:1）；error `#A33D36`（6.41:1）
- 项目扩展 token：`--map-paper: #F9F0D8`（地图容器纸底）、`--surface-translucent: rgba(255,255,255,.97)`（固定层与吸顶区统一半透明纸面）、`--text-inverse`、`--success/warning/error-border`（提示条描边）

## 本轮改动（2026-10-10）

**容器与对齐**

- 新增 `--page-max: 1200px` 与 `--page-pad` 流体边距；`.top-bar` 与 `.locations-page` / `.management-page` 统一最大宽度并居中，顶栏分隔线随内容内缩；移除地点页 1060px、旅行页 1200px 的独立上限。
- 工作台（地图工作台 / 行程编排）保持全宽布局；≤1180 与 ≤900 断点下顶栏与工作区同边距。
- 列表卡片与工具条内边距对齐（4px 修正）。

**Token 消费**

- 地图纸底、定位蓝、提示边框、焦点环、半透明纸面、反色文字全部改为语义 token，消除散落的字面色值。

**步骤指示统一**

- 旅行攻略三步条改为与导入向导一致的「编号圆点 + 连接线」语言（激活步黄色圆点 + 墨色标签、未达步中性）。

**导航语义**

- 行程图标 `⇢`（路程）、攻略图标 `⚑`（旗帜），消除原 `→` / `⇢` 双箭头难以区分的问题；桌面侧栏与移动底栏同步更新。

**交互真实性**

- 空间卡片改为只读信息块（原为带下拉箭头但无实际行为的按钮）；回收站角标由错误红改为墨色中性计数（选中态下仍可读）。
- 列表筛选空态新增「清空筛选」动作（原按钮与空态原因不匹配）；旅行攻略按钮禁用时提示缺失原因；「选填」标注统一为标签后缀，占位符只留示例；修正未定位提示中过期的「海报」文案为「分享」。

**地图**

- 地图首次载入自动适配视野到数据范围（发现小馆模式保持用户视野；地点工作台 / 行程编排 / 共享页生效），行程编排中平潭等外地行程不再停留在福州默认视野。
- 行程描述框禁用拖拽缩放，避免拖柄破坏面板布局。

## 验证

- `npm run check`（语法 + Vercel functions + 生产构建）通过；`npm test` 93/93 通过；`npm run test:e2e` 49 通过 / 4 跳过 / 0 失败。
- 容器对齐浏览器实测：1920 / 1440 / 1280 / 1024 / 900 五档宽度下，地点管理、旅行攻略、我的、回收站、地图工作台的「顶栏标题 ↔ 内容左缘」差值均为 0px。

- 键盘焦点抽查与减弱动效规则沿用既有实现，未改动。
