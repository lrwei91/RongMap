# 2026-10-10 性能优化记录

核验时间：2026-10-10 01:12（Asia/Shanghai）；基线提交：`05873da`。以下是本地构建与 Chromium 结果，不代表生产网速或手机真实帧率。

## 改动

- 行程、管理、登录和公开分享页面按路由加载，保留原有业务流程与加载提示。
- 地图标记只在内容、坐标、层级或名称变化时调用 SDK；点击事件读取最新回调和地点数据，避免父组件回调变动触发全部标记刷新。
- 地图复用已定位地点集合；空路线参数保持稳定，避免无关渲染触发路线清理。
- 行程编辑与分享页缓存路线和标记数据；编辑页缓存候选地点与草稿序列化结果，发现页缓存已收藏 ID 集合。
- 移除 App 中重复的地点标准化，继续由 `loadBootstrap` 统一处理。
