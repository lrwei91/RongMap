# RongMap 共享版视觉改版简报

## 设计判断

这是一个面向亲友共享地点整理与地图回看的工作台，首要任务是**搜地点、看地图、筛选整理、协同维护并完成分享或导航**。本次继续采用“白纸油墨编辑风”：以白纸、黑墨和荧光黄建立清晰的编辑式工具界面；地图保留高德地图的真实地理信息表现，不把外部地图瓦片伪装成 RongMap 自有视觉。

这是一次**产品级共享改版**：保留地点数据语义和地图核心行为，新增空间导航、成员、标签、导入、活动记录、回收站、实时同步和只读分享；旧 API 在一个迁移发布周期内保持兼容。

## 视觉旋钮

| 旋钮 | 本项目值 | 调整原因 |
| --- | ---: | --- |
| `DESIGN_VARIANCE` | `4` | 工具型地图需要稳定的地图—列表对齐，不采用作品集式大标题叠画和高错位构图。 |
| `MOTION_INTENSITY` | `3` | 地点管理优先于品牌动效；只保留按钮反馈、抽屉/弹层揭示和移动端面板过渡。 |
| `VISUAL_DENSITY` | `6` | 地图、筛选、收藏列表和操作按钮需要同时可见；通过细线、标签和留白控制密度，而不是堆叠浮层。 |

## 保留与淘汰

### 保留

- 高德地图作为主要空间浏览和定位表面。
- 桌面端“一级导航 + 紧凑地点列表 + 固定地图”三栏工作台。
- 移动端地图优先、五入口底部导航、抽屉和底部弹层。
- 地点分类、标签、搜索、组合筛选、详情抽屉、编辑、软删除、导航、导入和导出能力。
- 无地点、加载失败、未定位和无筛选结果等现有状态。

### 淘汰

- 冷银灰、蓝色渐变、青绿色主按钮和紫色分类主视觉。
- 全局半透明玻璃、重复阴影和同质化悬浮卡片。
- 通过多套圆角、阴影和色板制造层级的做法。
- 分享海报失败回退中的蓝绿渐变占位图。
- 仅为加载字体而引入的外部展示字体请求，改用系统无衬线字体栈。

## Token 与组件决策

- 页面基底使用 `#FFFFFF`，主要文字使用 `#1A1A1A`，普通边界使用 `#E8E8E8`。
- `#FFE28A` 只承担品牌强调、选中态和低面积提示；业务成功、警告、错误仍使用独立语义颜色。
- 页面使用 32px 低透明度正交细网格，卡片使用白色表面和细边框，常态不使用阴影。
- 控件、列表卡片、抽屉和弹层统一使用语义 token；React 组件按工作流拆分，不依赖旧 DOM ID 契约。
- 地点分类徽标从 JavaScript 内联色值改为语义类名：餐饮使用黑墨，景点使用绿色状态色，日咖夜酒使用警示棕色。
- 分享海报的地图失败回退改为暖纸底、细网格和黑墨定位标记，与页面的纸墨语言一致。

## 运行约束与偏离项

- 地图瓦片、地图控件和高德信息窗仍由高德 SDK 渲染，这是业务真实性和地图可用性的必要偏离，不重绘为装饰性示意图。
- 桌面端采用约220px导航、380–440px地点栏和剩余宽度地图；地图固定在620–820px高度范围，不被长列表拉伸。
- 页面固定浅色模式，显式声明 `color-scheme: light`；不因系统深色偏好回退到旧版深色界面。
- 触屏端取消 hover 依赖，维持可点击尺寸；`prefers-reduced-motion: reduce` 下直接呈现稳定状态。

## 交付范围

- `src/`：React + Vite 应用、路由、纸墨 token、响应式工作台和完整共享工作流。
- `api/v2/` 与 `lib/shared-store.js`：空间鉴权、版本化地点、导入、回收站、成员、标签和只读链接接口。
- `supabase/migrations/`：共享空间数据模型、RLS 和 Realtime 发布配置。
- 地图 SDK 独立降级：地图加载超时或初始化失败时，显示纸墨风状态卡和重试入口；地点列表、搜索、编辑、删除与导出不被地图阻塞。
- 移动端加入地点与收藏列表作为模态底部面板管理焦点、Escape 关闭和焦点归还；桌面布局不误用隐藏语义。

## 验收矩阵

- 视口：320、390、768、1024、1440 CSS px。
- 状态：加载、成功、错误、空数据、筛选无结果、未定位、详情、编辑、软删除、导入、活动、回收站、邀请和只读链接。
- 输入：鼠标/键盘焦点、触屏按钮、Escape 关闭、`prefers-reduced-motion`。
- 真实性：地图瓦片和 POI 信息保持真实来源；分享海报的地图失败回退明确是占位地图，不伪装成真实地图数据。
- 运行态：至少执行静态资源 HTTP 检查、JavaScript 语法检查、HTML/CSS 结构检查和 Git 差异检查；浏览器远程调试不可用时，不把“代码可读”写成完整视觉验收。
